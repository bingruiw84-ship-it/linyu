# 醒城 · XingCheng Web

> 人 × 书 × 城 — 城市文化共创系统（网站版）

## 项目背景

「醒城」是一套以榆林图书馆为文化枢纽的"人×书×城"城市文化共创系统。本仓库为 **网站版** 的UI设计原型，与手机App形成互补：

- **App** 负责「探索与遇见」——户外NFC触发、即时互动
- **网站版** 负责「整理与创造」——室内深度浏览、创作、管理、社区

本项目为 **UXPA 2026 榆林公益命题** 参赛作品，赛道：智慧图书馆 × 城市文化品牌体验。

## 设计说明

### 视觉风格
- **瑞士极简主义**：干净排版、大量留白、网格系统、清晰层次
- **榆林色彩**：汲取丹霞地貌红色砂岩质感（暖赭石 #C45C3E、土黄 #D4A574、砂岩红 #B85450）
- **深色模式**：支持一键切换，适合夜间深度阅读与创作
- **多栏布局**：左侧导航 + 中间主内容 + 右侧信息面板
- **微动效**：节点连线流动、碎片卡片翻转、地图标记呼吸光晕

### 页面结构

| 页面 | 文件 | 核心功能 |
|------|------|----------|
| 首页/仪表盘 | `home.html` | "今天，怎么醒城？"入口与数据概览 |
| 城市知识图谱编辑器 | `graph.html` | 可视化编辑"人-地-书-事"关系网络 |
| 碎片管理与叙事工作室 | `studio.html` | 时间线式叙事创作环境 |
| 数据看板与年度报告 | `dashboard.html` | 探索轨迹统计、热力图、年度报告 |
| 古籍在线阅读与批注 | `ancient-reader.html` | 《榆林府志》等古籍对照阅读 |
| 社区论坛与作品展厅 | `community.html` | 内容沉淀型社交与作品展示 |
